# Next.js + Python Voice Assistant Kit

[![npm version](https://img.shields.io/npm/v/%40boyeep%2Fnextjs-python-voice-assistant-kit)](https://www.npmjs.com/package/@boyeep/nextjs-python-voice-assistant-kit) [![npm downloads](https://img.shields.io/npm/dm/%40boyeep%2Fnextjs-python-voice-assistant-kit)](https://www.npmjs.com/package/@boyeep/nextjs-python-voice-assistant-kit) [![license](https://img.shields.io/npm/l/%40boyeep%2Fnextjs-python-voice-assistant-kit)](https://www.npmjs.com/package/@boyeep/nextjs-python-voice-assistant-kit)

Realtime microphone, STT, streaming response, and TTS starter.

## Create a project

```bash
npx @boyeep/nextjs-python-voice-assistant-kit my-voice-app
```

Skip dependency installation when you only want the generated files:

```bash
npx @boyeep/nextjs-python-voice-assistant-kit my-voice-app --no-install
```

See the [template repository](https://github.com/Boyeep/nextjs-python-voice-assistant-kit) for setup, architecture, and development documentation.
