# Python Document Intelligence Kit

[![npm version](https://img.shields.io/npm/v/%40boyeep%2Fpython-document-intelligence-kit)](https://www.npmjs.com/package/@boyeep/python-document-intelligence-kit) [![npm downloads](https://img.shields.io/npm/dm/%40boyeep%2Fpython-document-intelligence-kit)](https://www.npmjs.com/package/@boyeep/python-document-intelligence-kit) [![license](https://img.shields.io/github/license/Boyeep/python-document-intelligence-kit)](https://github.com/Boyeep/python-document-intelligence-kit/blob/main/LICENSE)

OCR, extraction, validation, and structured output API starter.

## Create a project

```bash
npx @boyeep/python-document-intelligence-kit my-document-api
```

Skip dependency installation when you only want the generated files:

```bash
npx @boyeep/python-document-intelligence-kit my-document-api --no-install
```

See the [template repository](https://github.com/Boyeep/python-document-intelligence-kit) for setup, architecture, and development documentation.
