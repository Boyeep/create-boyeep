Streaming full-stack AI chatbot starter.

## Create a project

```bash
npx @boyeep/nextjs-python-ai-chatbot-kit my-chatbot
```

Skip dependency installation when you only want the generated files:

```bash
npx @boyeep/nextjs-python-ai-chatbot-kit my-chatbot --no-install
```

See the [template repository](https://github.com/Boyeep/nextjs-python-ai-chatbot-kit) for setup, architecture, and development documentation.
